## 📖 Overview
Bloom & Petal Haven is an online flower and plant shop designed to help people decorate their homes with greenery or surprise loved ones with meaningful gifts.  
The site offers a modern shopping experience with product listings, blog posts, and interactive features built with **HTML, CSS, and JavaScript**.

---

## 🚀 Features
- 🛒 Shop Page → Browse flowers, plants, and accessories
- 🎁 Gift Ideas → Curated suggestions for friends and family
- 📖 Blog Section → Articles with hidden content revealed by JavaScript
- 📱 Responsive Design → Works on desktop, tablet, and mobile
- 🎨 External CSS Styling → Clean and consistent look
- 🌐 GitHub Pages Deployment → Live demo link for easy access

---

## 🛠️ Technologies Used
- **HTML5** → Page structure and content
- **CSS3** → Styling and responsive layouts
- **JavaScript (ES6)** → Interactivity (toggle hidden content, buttons)
- **GitHub Pages** → Hosting the live site

---


---

## 💻 Usage
- Visit the homepage to explore featured products.
- Browse the shop for flowers, plants, and accessories.
- Read blog posts and click **Read More** to reveal hidden content.
- Use the contact page to reach out for orders or inquiries.
